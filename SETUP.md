# Yardscape Fresh Start
- Upload index.html, booking.html, admin.html, style.css and the entire assets folder to GitHub Pages.
- Create a standalone Google Apps Script project and replace Code.gs with apps-script/Code.gs.
- Deploy as Web app: Execute as Me; Who has access: Anyone.
- If Google gives a new /exec URL, replace API in booking.html and admin.html.
- Default admin key: Yardscape-maxAdmin.
- The first successful booking creates a Google Sheet named Yardscape Bookings.
- The server uses LockService and a final date/time check, so the same date/time cannot be booked twice.
- After changing Code.gs, deploy a NEW VERSION.
- The website does not use Instagram, Gallery, Why Choose Us, or Quick Links.
